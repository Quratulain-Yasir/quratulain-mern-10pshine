
# 📝 Note Nest – MERN Stack Note-Taking App

A full-stack note-taking application built with **MongoDB**, **Express**, **React**, and **Node.js**.

## 🚀 Features
- User authentication (register/login)
- Create, edit, and delete personal notes
- Rich text support for notes
- USER-PROFILE UI with React
- RESTful API with Express and MongoDB

## 🛠️ Tech Stack
- **Frontend:** React, Axios, Tailwindcss
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (Mongoose)
- **Authentication:** JWT, bcrypt

## 📦 Installation

1. **Clone the repo**
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   cd your-repo-name
   ```

2. **Install backend dependencies**
   ```bash
   cd backend
   npm install
   ```

3. **Install frontend dependencies**
   ```bash
   cd ../frontend
   npm install
   ```

4. **Set up environment variables**
   - Create `.env` files in both `backend/` and `frontend/` with necessary keys (e.g., Mongo URI, JWT secret)

5. **Run the app**
   ```bash
   # In backend/
   npm run dev

   # In frontend/
   npm run dev
   ```

## 📂 Folder Structure
```
/frontend   → React app
/backend    → Express API
```
